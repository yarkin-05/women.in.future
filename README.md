# women.in.future

Repositorio de recursos para aprender lenguajes de programación desde cero hasta nivel avanzado, con contenido gratuito y en español (cuando sea posible).

## 📚 Contenido por lenguaje

- [Java](./java/README.md)
- [Python](./python/README.md)
- [C](./c/README.md)
- [C++](./cpp/README.md)
- [SQL](./sql/README.md)
- [JavaScript](./javascript/README.md)

## 🎯 Objetivo

Crear una base de recursos accesible para la comunidad **Women in Tech**, organizada por lenguaje para facilitar el aprendizaje progresivo.

## 🤝 Cómo contribuir

1. Elige una carpeta de lenguaje.
2. Añade recursos útiles (documentación, cursos, libros, práctica, roadmap).
3. Mantén formato claro y enlaces actualizados.
4. Abre un Pull Request con tus cambios.

## ⭐ Recomendaciones generales

- Practicar todos los días aunque sean 20-30 minutos.
- Combinar teoría + ejercicios + mini proyectos.
- Documentar tu progreso en GitHub.
- Participar en comunidades de apoyo.
